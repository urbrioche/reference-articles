FastAPI 乾淨架構 (Clean Architecture) 設計指南

本指南彙整了在 FastAPI 專案中實現高內聚、低耦合，並完美防堵抽象洩漏（Leaky Abstraction）的實戰架構心法。

核心心法：防腐層設計 (Anti-Corruption Layer)
外層（Router/基礎設施）只能依賴內層（Service/領域），內層絕對不能知道外層（HTTP 框架、資料庫引擎）的存在。所有的資料進出都必須經過「轉譯」。

1. 分層職責與命名矩陣

架構層級 職責說明 資料載體命名建議 絕對禁止出現
Router (對外介面) 處理 HTTP 協定，擔任出入境海關轉譯資料。 {名詞}Request, {名詞}Response 核心業務邏輯、直接呼叫資料庫
Service (業務邏輯) 執行核心商業規則，協調 Repository 與外部 API。 {動詞}Command, {動作}Query HTTP 狀態碼、Pydantic HTTP 驗證參數
Domain (領域模型) 自帶驗證的業務實體與值物件 (Value Objects)。 {名詞}Entity, Money, Email 任何框架依賴、關聯式資料庫的外鍵概念
Repository (資料存取) 封裝資料庫操作 (ORM/Raw SQL)，回傳 Entity。 {名詞}ORM, {名詞}Model API Schema、業務邏輯判斷
Gateway (外部服務) 封裝對第三方 API 的 HTTP 請求。 {第三方}Gateway, {服務}Client 核心業務邏輯

2. 資料流與解耦轉譯模型 (CQRS)

嚴格分層下，資料進出必須遵循以下轉譯路徑，確保核心層不被外部框架綁架：

  • 寫入 (POST/PUT)：HTTP JSON (Request) ➔ Router 轉譯 ➔ Command ➔ Service ➔ Entity ➔ Router 轉譯 ➔ HTTP JSON (Response)
  • 讀取 (GET)：URL Params (Params) ➔ Router 轉譯 ➔ Query ➔ Service ➔ Entity ➔ Router 轉譯 ➔ HTTP JSON (Response)

3. 關鍵防線實作範例

A. 統一的業務例外處理 (Domain Exceptions)

Service 不該拋出 HTTPException，應拋出自訂領域例外，由 main.py 統一攔截。

# core/exceptions.py
class BaseDomainException(Exception):
    status_code: int = 400
    error_code: str = "DOMAIN_ERROR"
    
    def __init__(self, message: str):
        self.message = message
        super().__init__(self.message)

class InsufficientBalanceError(BaseDomainException):
    status_code = 400
    error_code = "INSUFFICIENT_BALANCE"

# main.py 攔截器
@app.exception_handler(BaseDomainException)
async def domain_exception_handler(request: Request, exc: BaseDomainException):
    return JSONResponse(
        status_code=exc.status_code,
        content={"error_code": exc.error_code, "message": exc.message}
    )

B. Repository 隔離 Raw SQL 洩漏

無論用 ORM 還是 Raw SQL，Repository 必須將資料列解構並封裝為純 Domain Entity 再回傳。

# repositories.py
class UserRepository:
    async def get_user(self, user_id: int) -> UserEntity | None:
        # 查詢 Raw SQL
        row = await self.db.fetch_one("SELECT * FROM users WHERE id = :id", {"id": user_id})
        if not row: return None
        
        # 攔截 Row 物件，轉譯為純 Python Entity
        return UserEntity(
            id=row["id"], 
            username=row["usr_nm_db"] # 隔離資料庫命名污染
        )
